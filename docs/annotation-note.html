The Annotation Note

A callout that reads as paper slapped onto the page. Severity is ink pressed into the sheet, not a coloured border on a rounded box.

The ripple texture in this file is a CSS stand-in. The real Change in Ripples motif is an Adobe Illustrator Blend Tool construction and no SVG exists in this repo. Swap it in and recompute every contrast ratio below, because the texture sits under the ink and shifts the effective background.

Rules

  1. Never let the label repeat the stamp. WARNING above COMPETITIVE RISK says the same thing twice. If the stamp carries the severity word, the label drops it.
  2. Rotation collapses below 640px. Set rotate(0) or the note overflows its column. The stamp keeps its own angle.
  3. Attachments are rare and carry no meaning. Severity always comes from the stamp. A red dot and a grey dot are the same dot in greyscale.
  4. The stamp is the only severity channel. No left border, no additional icon, no per-state background. One device, one job.
  5. Minimum stamp type is 21px. Below that the knocked-out word loses its counters and the multiply blend muddies it.
  6. The warning ink is brown, and that is correct. Multiply over yellow drags red toward brown. Every true red that survived the blend failed WCAG.

Open items

  1. The ripple texture is a stand-in. Recompute all ratios against the real SVG.
  2. The stock inverts a sanctioned pairing. boldr-brand-2025.md lists Sun on Boldr Orange; this note uses sun stock with orange ripples. Needs a brand decision.
  3. boldr-brand-2025.md line 74 assigns Big Shoulders 800 to callouts. The stamp uses 900. Either change it or document the exception.
  4. The text-wrap system is unbuilt: margin note, float with square and tight wrap, block interrupt, column overlap, each needing a declared narrow-width collapse.
